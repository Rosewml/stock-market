# 系统地图

## 应用入口

- `app/app.vue`：当前主页面，实现股票管理、手机预览、主题选择和下载设置三栏布局。

## 文档与原型

- `docs/requirements.md`：中文需求文档。
- `docs/prototype/stock-market-prototype-1920x1080.png`：保存的原型图。
- `docs/prototype/agent-browser-layout-check.png`：当前 agent-browser 视觉检查截图。

## 构建配置

- `package.json`：Nuxt 脚本定义。
- `nuxt.config.ts`：Nuxt 配置。

## 当前 UI 结构

- 左侧：股票管理、添加股票、预设股票表格。
- 中间：手机界面预览，含三套主题响应式展示。
- 右侧：主题选择、图片格式、下载按钮。
